# 🧪 DES Research Chatbot (Streamlit App)

A Retrieval-Augmented Generation (RAG) chatbot for analyzing **Deep Eutectic Solvent (DES)** research papers.

Upload PDFs, ask questions, and get AI-generated answers grounded in your documents.

---

## 🚀 Features

- 📄 Upload multiple research papers (PDF)
- 🔍 Semantic search using embeddings (FAISS)
- 🤖 LLM-powered answers (Hugging Face Transformers)
- 🧠 Context-aware responses from your documents
- ⚡ Simple Streamlit interface

---

## 🏗️ Tech Stack

- **Streamlit** – Web app UI
- **Sentence Transformers** – Text embeddings
- **FAISS** – Vector similarity search
- **Transformers (Hugging Face)** – Language model
- **PyPDF** – PDF text extraction
- **PyTorch** – Model backend
